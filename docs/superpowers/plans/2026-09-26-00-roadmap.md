# Text2SQL — Implementation Roadmap

**Spec:** `docs/superpowers/specs/2026-09-26-text2sql-design.md`

Spec được triển khai qua 8 plan tuần tự. Mỗi plan tạo ra phần mềm chạy được và demo được. Plan N+1 chỉ được viết sau khi Plan N đã merge, để dựa trên code thật chứ không đoán trước.

| # | Plan | Phạm vi (mục trong spec) | Demo khi xong | Interface tạo ra cho các plan sau |
|---|---|---|---|---|
| 01 | Foundation | §1, §5 (users, app_settings), auth, khung §6 | `docker compose up` → đăng nhập 3 role → thấy app shell; warehouse đã seed; role DB read-only | `Settings`, `create_app`, `get_session`, `CurrentUser`, `require_min_role`, `Settings.warehouse_dsn(role)`, `apiFetch`, `useAuth`, router + `AppShell`, design tokens |
| 02 | Core pipeline | §2 (semantic layer, linker, generator 1 provider, validator cơ bản, executor), SSE, màn Ask | Hỏi → SQL → bảng kết quả + chart, trace hiển thị trực tiếp | `PipelineContext`, `Step` protocol, `LLMProvider`, `/api/query` SSE event schema, bảng `query_runs`/`pipeline_steps`/`llm_calls`/`schema_embeddings` |
| 03 | Guardrails | §3.1 (L1–L5), che PII theo role | Bộ test tấn công ≥60 case pass; viewer thấy email đã che | `guardrail_events`, bộ mã guardrail |
| 04 | LLM router & fallback | §3.2 | Bật chaos tắt Claude → trace hiển thị failover; tắt hết → rule-based trả lời | `LLMRouter`, circuit breaker, `rule_based.match()`, `app_settings.llm_chain/chaos` |
| 05 | Judge, risk gate, repair | §3.3, §3.4 | Trace hiện verdict của judge + confidence; câu mơ hồ → NEEDS_REVIEW | `judge_verdicts`, `RiskDecision` |
| 06 | HITL | §4.1 | Analyst duyệt/sửa → viewer nhận kết quả; câu tương tự sau đó tự chạy | `review_items`, `verified_examples`, `user_feedback`, `judge_disagreements`, kênh SSE thông báo |
| 07 | Eval harness | §4.2, CI gate | `make eval SUITE=smoke`; trang Evaluation; CI chặn khi kết quả giảm | `eval_cases/runs/results`, cassette, `eval/baseline.json` |
| 08 | Ops, Admin, hoàn thiện | §6 (Ops, Settings), README, kịch bản demo | Ops dashboard, cấu hình chain/ngưỡng/chaos trên UI | — |
